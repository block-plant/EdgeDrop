Designed for Focus

Built to stay out of your way.

No system trays full of bloat. No popups asking for subscriptions. Just an edge-docked utility that appears when needed and retreats when you are done.

01

Magnetic edge docking

Rests flush on your left or right screen border as a 14px discreet pill. Retracts automatically when you switch apps, scroll, or switch virtual desktops. Opens smoothly the instant you drag a file toward it.

02

Adaptive wallpaper tinting

Reads your desktop background directly via native OS window APIs without requesting screen-recording permissions. Clamps color saturation and luminance dynamically so UI text remains legible in every lighting condition.

03

Honest target-size math

Never re-encodes a file that is already under your target ceiling. Uses high-precision binary search on encoding quality, stops at the visual clarity threshold, and explains size ceilings in plain English.

04

Runs only when you want it

Zero login items forced on installation. Single-instance launcher isolated to the current user via secure local IPC. Zero background telemetry pingbacks and one-click clean quit.

Engineering

Deep format compression. Zero cloud roundtrips.

Every format compressor in EdgeDrop is written in pure C++20 with verified mathematical boundaries.

Photos & Raster Graphics

Combines high-precision binary search quality tuning for JPEG and WebP with indexed palette quantization for PNG. Inspects the visual entropy of images to stop compression before blocking artifacts appear. Automatically scrubs GPS location coordinates and camera serial numbers upon export.

Offline Architecture

Your files never leave your desk.

EdgeDrop is compiled in pure C++20 with zero network code. Every untrusted file passes through strict parser guards before a single byte is written.

ZERO NETWORK
Completely Air-Gapped Operation

No HTTP client, no analytics pingbacks, no update check queries. The app operates identical on a plane with Wi-Fi disabled.

PARSER GUARDS
Resource Exhaustion & Traversal Defense

Zip Slip directory traversal rejection, Zip Bomb mitigation (100:1 / 500 MB inflation ceiling), 100 MP image bomb limits, and symlink read blocking.

SANDBOX RUNNER
Isolated Subprocess Execution

Subprocesses execute strictly via direct argv vectors with no shell interpreter. Ghostscript runs with -dSAFER; FFmpeg restricts protocols to file,pipe.

PRIVACY BY DEFAULT
EXIF GPS Stripping & Owner-Only Files

Strips camera serial numbers and location tags from images. Intermediate temp files use owner-only permissions (0600) and unlink on scope exit.

HARDENED BINARIES
Defense-in-Depth Compiler Flags

Compiled with stack-protector-strong, _FORTIFY_SOURCE=2, ASLR, DEP, and CFG guards. Machine paths are stripped via file-prefix-map.

A quick note before you open EdgeDrop

EdgeDrop is an independent, 100% offline utility — your files never leave your device. Because it is currently distributed as an indie build without a commercial Apple or Microsoft signing certificate ($99–$499/year), your system may show a standard one-time prompt on first launch:

Apple Gatekeeper may display “EdgeDrop cannot be opened because Apple cannot check it for malicious software” on first run.

  1. Right-click (or Control-click) EdgeDrop.app in your Applications folder.
  2. Choose Open from the context menu, then click Open again.
  3. Or remove quarantine via Terminal: xattr -cr /Applications/EdgeDrop.app

Windows SmartScreen may display “Windows protected your PC” for new community releases.

  1. Click “More info” in the dialog.
  2. Select “Run anyway”.
  3. EdgeDrop installs cleanly to your local user directory with no administrative UAC prompt.

Ensure the AppImage file is marked as executable before running:

  1. Open your terminal in the directory where the file was downloaded.
  2. Execute: chmod +x EdgeDrop-*.AppImage
  3. Launch via ./EdgeDrop-*.AppImage or double-click in your desktop environment.

Android may display “File might be harmful” or ask for permission to install apps outside Google Play:

  1. Tap Download anyway in the browser prompt.
  2. Open the downloaded .apk from notifications or your Downloads folder.
  3. When prompted, tap Settings → enable “Allow from this source”, then tap Install.
